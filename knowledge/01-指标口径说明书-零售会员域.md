# 指标口径说明书 · 零售会员域

本文件用于统一零售会员域（数据集 B）核心指标的计算口径。各口径与语义层 `mdl.json` 中
的字段定义一一对应，凡本文件与本文件之外的口径冲突，以语义层模型定义为准。

## 一、门店坪效

**口径**：坪效 = 销售额 ÷ 门店经营面积。

- 销售额取 `dws_store_daily_agg.sales_amount`（当日销售额，元）；
- 面积取 `dws_store_daily_agg.area_sqm`（平方米）；
- 面积按门店固定，同一门店各日期的面积值一致。

**用途**：对比不同规模门店的单位产出。面积不同但销售额相同的两家门店，坪效并不相同。

**常见误用**：用订单行数除以面积。坪效衡量的是销售额产出，不是交易笔数。

## 二、销量（销售件数）【新增口径】

**口径**：销量（销售件数）= `SUM(dws_store_daily_agg.sales_qty)`，即门店每日售出的商品件数汇总。

- `sales_qty` 取自 `dws_store_daily_agg.sales_qty`（当日销售件数，单位：件）；
  本口径为**新增字段**，与语义层 MDL 同步上架，凡未上架前不得用于分析。
- **销量 ≠ 销售额**：销售额是金额（元），取 `dws_store_daily_agg.sales_amount`；
  销量是数量（件）。二者量纲不同，不得混用或相互替代。
- **销量 ≠ 订单数**：`dws_store_daily_agg.order_cnt` 是订单笔数；一笔订单可含多件商品，
  销量（件数）通常 ≥ 订单数。不得以订单数充当销量。

**用途**：回答"卖了多少件"而非"卖了多少钱"，用于客单件数、商品动销等分析。

**常见误用**：把 `sales_amount`（金额）或 `order_cnt`（订单数）直接当成销量；三者必须区分。

## 三、复购率

**口径**：复购率 = 复购用户数 ÷ 活跃用户数。

- 复购用户数 = `SUM(ads_member_repurchase_di.repurchase_flag)`，其中 `repurchase_flag`
  取值 0/1，1 表示该会员当月下单两次及以上；
- 活跃用户数 = 当月有下单行为的会员数（即 `dim_member.member_status = '活跃'` 的口径人群）。

**硬性要求**：复购率必须**随附分母**。只给一个百分比而不给活跃用户数，
该结论不可采信——分母口径一变，比率立刻变。

**禁止事项**：不得用流失会员充当分母。`dim_member.member_status` 枚举为
活跃 / 沉默 / 流失，其中"流失"是历史状态，不是当期活跃口径。

## 四、订单金额

**口径**：订单金额 = `SUM(dwd_order_detail_di.sales_amount)`，**不含退款单**。

- `sales_amount` = 数量 × 成交单价；
- 剔除退款的方式是按订单状态过滤（见下条）；
- `dwd_order_di.pay_amount` 是单笔订单的实付金额，与明细汇总口径不同，二者不可混用。

## 五、订单状态与退款

`dwd_order_di.order_status` 枚举只有两个取值：**已完成 / 已退款**。

统计销售额、订单数时，默认只计入"已完成"。若需求方需要含退款的毛口径，
必须在需求单中显式写明，否则按不含退款处理。

## 六、业务日期与装载时间

- 分析一律使用 `dwd_order_di.order_date`（业务日期）；
- `dwd_order_di.load_time` 是数据装载时间，**不是业务日期**，不得用于任何业务时间口径的筛选。

常见错误：用装载时间过滤"最近一个月"，会把补跑的历史数据错误地算作当期业务。

**自然月口径（默认）**：需求中的"本月度 / 月度 / 当月"默认指**自然日历月**
（如 2026-09 即 2026-09-01 ~ 2026-09-30 闭区间），按业务日期字段
（`order_date` / `stat_date`）过滤。除非需求方**显式说明"最近 30 天"**，
否则不按滚动 30 天口径处理。

## 七、门店大区与门店类型

- `dim_store.region_name` 枚举：**华东大区 / 华北大区 / 华南大区**，无其他取值；
- `dim_store.store_type` 枚举：**直营 / 加盟**。

若需求中出现"西南大区"等在册枚举之外的取值，属于枚举越界，需先确认大区口径是否存在，
不得直接返回空结果。

## 八、会员等级与状态

- 会员等级 `dim_member.grade` 枚举：**普通 / 银卡 / 金卡 / 钻石**；
- 会员状态 `dim_member.member_status` 枚举：**活跃 / 沉默 / 流失**；
- 等级异动记录在 `ads_member_grade_change_wi`，`change_type` 枚举为 **升级 / 降级**，
  时间粒度为月（`change_month`）。

## 九、券核销相关口径（待上架）

`ads_coupon_order_di` 表已建，但以下口径**尚未上架**，当前不可用于分析：

- 按券种（满减券 / 折扣券 / 新人券）细分核销；
- 券成本口径（`coupon_amount` 的成本归集方式）；
- 核销 GMV 口径（`order_gmv` 的统计范围）。

需要这三项口径时，须先走口径上架流程并更新本文件，不得自行推定。

此外，券核销表与订单表之间**没有建立关联关系**，涉及"用券订单的销售明细"一类问题的，
应先确认关联主键，不要假设两表可以直接 JOIN。

## 十、口径变更

本文件所列口径来源于语义层模型定义。口径调整时需同步更新语义层并重新发布 MDL，
发布后本文件随之更新版本。
