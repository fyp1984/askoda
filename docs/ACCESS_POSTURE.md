# 本地单租户访问姿态说明 · 数据需求智能分析助手

> 版本：v1.0 · 2026-10-21
> 适用范围：当前 `main`（含 PR#16 REQ-COVERAGE 阶段二）及本交付就绪分支
> 对应：MVP 完整度审查（2026-10-21 §十）硬伤②「零入站鉴权 + 零多租户」的正式处置说明

## 一、结论（先读这段）

**当前工程处于开发 / 测试期，定位为「本地单租户」部署：没有入站鉴权，也没有多租户隔离。**

这是 MVP 审查确认的两项阻断硬伤之一（②），按项目铁律「开发测试期不做生产级加固」**本次不做实现**，改为在本文件明确边界与限制，生产环境（P3 阶段）再补齐。

- 任何人只要能连上 BFF / 网关端口，就能查看**全部需求单、SQL 交付记录、运行元数据**，且**无法区分租户**。
- 当前唯一的网络防护是 **BFF 绑定 `127.0.0.1` 回环地址**（`docker-compose.yml:245`），不绑 `0.0.0.0`。
- **禁止把任何服务端口暴露到公网或不可信局域网。** 绑 `0.0.0.0` 等于把全部数据对同网段任意主机开放。

## 二、暴露面（端口与绑定）

| 服务 | 宿主机端口 | 容器端口 | 绑定地址 | 说明 |
|---|---|---|---|---|
| BFF（前端入口） | `18081` | `18081` | **`127.0.0.1`** | 浏览器入口 `http://127.0.0.1:18081/`；当前唯一回环防护 |
| 网关 MCP | `18080`（可配 `GATEWAY_HOST_PORT`） | `8080` | 默认 `0.0.0.0` | MCP 端点 `/mcp`，根路径 404 属正常 |
| 网关元数据库 Postgres | `15434` | `5432` | 默认 `0.0.0.0` | 运行元数据（需求单 / 留痕 / 字典），**非业务数据源** |
| MinIO（附件） | `9000/9001/18000/18001` 等 | — | 默认 `0.0.0.0` | 附件对象存储；默认口令见 `.env.example` |
| 本地 Embedding（TEI） | `18002` | `80` | 默认 `0.0.0.0` | RAGFlow 召回依赖，仅本机内部消费 |

> 端口数值以 `docker-compose.yml` 当前声明为准；带 `:-` 默认值的均可经 `.env` 覆盖。
> 网关 / Postgres / MinIO / TEI 默认绑 `0.0.0.0` 是为本地联调方便，**不意味着可对外暴露**——访问它们应经本机或受信网络转发，而非直接公网开放。

## 三、已知限制与风险

1. **无身份校验**：BFF 与网关均不校验调用者身份（`actor` 为自由文本直传，无 `/me` / `role`）。能连上即视为合法用户。
2. **无租户隔离**：全部需求单、分析记录、元数据库共享同一命名空间，无法按组织 / 用户隔离数据。
3. **默认弱口令**：`.env.example` 中的 `ASSISTANT_PG_PASSWORD` / `MINIO_ROOT_PASSWORD` 等为开发默认值，**上生产前必须替换**。
4. **知识库（RAGFlow）缺口**：`KNOWLEDGE_API_KEY` / `KNOWLEDGE_DATASET_ID` 默认留空，知识检索能力不可用（已知边界，非配置错误）。

## 四、部署边界（开发 / 测试期必须遵守）

- 仅在**本机回环**或**受信私有网络**内访问；不要将 `0.0.0.0` 绑定的端口映射到公网。
- 对外演示时，用反向代理 + 临时访问口令兜底，**不要长期暴露**。
- 不要用默认弱口令跑任何「类生产」环境；至少先把 `ASSISTANT_PG_*` / `MINIO_ROOT_*` 改为强随机值。
- 多用户 / 多组织场景一律**不要**用当前版本承载真实业务数据。

## 五、生产前必做（P3 清单，非本次范围）

| 项 | 动作 | 入口 |
|---|---|---|
| 入站鉴权 | BFF / 网关加 bearer token 或 API key 校验；前端加登录态 | `bff/app.py`、`gateway/app.py` |
| 多租户隔离 | 元数据库按租户行级隔离 / 命名空间；所有查询强制带 tenant 上下文 | `gateway/db.py`、需求单模型 |
| 密钥管理 | 接 KMS / 外部 secret，杜绝 `.env` 明文弱口令 | `docker-compose.yml` 环境变量层 |
| 绑定加固 | 确需对外时再放开 `0.0.0.0`，并叠加 WAF / 限流 | `docker-compose.yml` ports |
| 审计 | 操作留痕与身份绑定（当前留痕存在但无身份） | `gateway/evidence.py` |

> 排期归属：鉴权 / 多租户在既有产品优化落地排期中归 **P3（企业就绪）**，对应优化提案 O 系列与审查报告 R 系列，不在本次 P0/P1 交付就绪范围。
