# 遗留与未闭合项清单

> 本清单登记**本批（代码 + 门禁）交付时已知未闭合**的事项。
> 纪律：**每条必须有「触发条件」与「依赖」**——没有触发条件的待办等于没登记，
> 会让人以为「反正早晚做」而永远不做。
>
> ⚠️ **回滚点的口径**：本机（沙箱）**删不掉文件**（安全策略禁删）⇒
> **「回滚」不能靠删除，只能靠覆盖**。真正的回滚点必须**版本化、可重复**：
> git 提交（`git checkout <commit> -- <file>`）、DB 快照 SQL、或容器镜像 tag。
> 「本地留个备份文件」**不算回滚点**（覆盖 = 覆盖，不是回滚）。
